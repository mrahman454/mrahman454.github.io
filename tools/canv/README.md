# CANV (co-authorship network) — local copy

`template.html` is a modified copy of `template.html` from
[CANV: Co-Authorship Network Visualization](https://github.com/Xovee/canv) by Xovee Xu,
which builds on [webweb](https://github.com/dblarremore/webweb). Both are licensed under
the GNU GPL v3.0 (see `LICENSE`).

Changes made here (November 2026):

- The embedded network data is replaced by a `/*CANV_DATA*/` placeholder.
- The original author's hard-coded name is replaced by a `__CANV_CENTRE__` placeholder
  (the highlighted centre node).
- The standalone page heading/intro is hidden and the styles are adjusted so the page
  can be shown inside the website (`/coauthors/`).
- Several nodes can be highlighted (`/*CANV_CENTRES*/` list), so the same template also
  draws the institution network with all of my institutions highlighted.
- Control labels use `__CANV_SINGULAR__` / `__CANV_PLURAL__` (co-author / institution).
- Colours, fonts and the canvas height follow the website's fun/serious mode.

The pages are generated by `scripts/build_coauthor_network.py`, which reads the author lists
in `_publications/` (and affiliations saved in `_data/affiliations.json`, from OpenAlex) and
writes `assets/canv/coauthors.html` and `assets/canv/institutions.html`. It does the same graph
construction as CANV's `canv.py` (edge weight 1/(n−1) per paper with n authors), using only
the Python standard library.
